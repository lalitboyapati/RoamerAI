There is **no application server**. The browser talks to Typesense directly with a search-only API key scoped to `documents:search` on `features_*`. That's the whole backend, and it's a talking point ("Typesense is the backend").

## 4. Document schema (one per feature — the contract between pull, index, and frontend)

```jsonc
{
  "id": "gemma-2-2b_12_4232",          // {model}_{layer}_{index}; no slashes/spaces (Typesense id rule)
  "model": "gemma-2-2b",               // facet
  "layer": 12,                         // int32, facet  → per-layer counts come from here
  "index": 4232,                       // int32          → feature index within the layer
  "description": "references to protein folding and tertiary structure",   // primary, keyword-indexed
  "descriptions": ["references to protein folding ...", "..."],           // all explanations (string[])
  "explainer": "gpt-4o-mini",          // facet, optional
  "source": "12-gemmascope-res-16k",   // stored, not indexed
  "np_url": "https://www.neuronpedia.org/gemma-2-2b/12-gemmascope-res-16k/4232",  // stored, not indexed
  "embedding": [/* 384 floats, features_deep only, generated by Typesense at import */]
}
```

Both collections share every field; `features_deep` adds `embedding` (auto-embedded from `description` with `ts/all-MiniLM-L12-v2`).

## 5. Search contract (browser ↔ Typesense)

**Request** — one `multi_search`, one search per model the UI is showing (1 for single, 2 for Compare):

```jsonc
POST {protocol}://{host}:{port}/multi_search
X-TYPESENSE-API-KEY: <search-only key>
{
  "searches": [
    { "collection": "features_fast", "preset": "roamer_fast", "q": "protein folding", "filter_by": "model:=gemma-2-2b" },
    { "collection": "features_fast", "preset": "roamer_fast", "q": "protein folding", "filter_by": "model:=llama3.1-8b" }
  ]
}
```
Deep mode: `collection: "features_deep", preset: "roamer_deep"`. Nothing else changes. Presets carry `query_by`, `vector_query`, `facet_by`, `per_page`, etc. (see 03).

**Response** — per search:

```jsonc
{
  "found": 143,                                // total matches (this drives the score — no paging)
  "facet_counts": [{ "field_name": "layer", "counts": [{ "value": "12", "count": 31 }, ...] }],
  "hits": [                                    // up to 250 (per_page max), best first
    { "document": { "id": "...", "model": "...", "layer": 12, "index": 4232, "description": "...", "np_url": "..." },
      "text_match": 578730123365187705,        // Fast + Deep (keyword component)
      "vector_distance": 0.31,                 // Deep only; cosine distance, lower = closer
      "hybrid_search_info": { "rank_fusion_score": 0.85 },   // Deep only
      "highlight": { "description": { "snippet": "... <mark>protein</mark> <mark>folding</mark> ..." } } }
  ]
}
```

The frontend needs exactly three things from this: `found`, `facet_counts[0].counts`, and `hits[].document.{layer,index,description}` (+ a relevance number for glow intensity: `rank_fusion_score` if present, else rank position).

## 6. Coverage score (the number judges see)

Inputs per (model, mode) after a search:

- `found` — matching features
- `indexed` — `manifest.models[model][mode].total` (425,984 for Gemma fast; ~26,624 for Gemma deep; etc.)
- `perLayer` — from `facet_counts`
- `nLayers` — `manifest.models[model].n_layers`

```ts
const density = found / (indexed / 1000);                       // hits per 1,000 indexed features (size-normalized)
const layersHit = Object.keys(perLayer).length;
const spread = layersHit / nLayers;                             // 0..1, how many layers carry the concept
const D0 = mode === "fast" ? 2.0 : 6.0;                         // density that counts as "saturated" — TUNE
const score = Math.round(100 * Math.min(1, Math.sqrt(density / D0)) * (0.5 + 0.5 * spread));
```

One-sentence version for judges: *"How many features fire for the concept, normalized by model size, weighted by how many layers the concept spans."*

Why each piece:
- **Normalize by `indexed`** so Llama (2.5× more features) doesn't win by default, and so Fast and Deep are on the same scale despite Deep being a sample.
- **`sqrt`** compresses: 4× the hits ≈ 2× the score. Keeps common concepts from pinning at 100.
- **Spread** rewards concepts represented across the network (a genuine "the model thinks about this" signal) over a single lucky layer.

Calibrate `D0` at ~9:00 PM so `protein folding` on Gemma lands ~60–80 in both modes. Store `D0` in one constant file (`frontend/src/coverage.ts`).

**Per-layer bar** = `perLayer[L] / max(perLayer)` for `L in 0..nLayers-1`, zeros included. Same component in both models so the visual compare is fair.

## 7. Node placement (deterministic, no layout algorithm)

```
y = layer * LAYER_GAP                          (discs stacked vertically; layer 0 at the bottom)
h1, h2 = hash(model, layer, index) → two floats in [0,1)   (e.g. mulberry32 seeded from a string hash)
angle = h1 * 2π ;  r = DISC_RADIUS * sqrt(h2)  (sqrt → uniform over the disc)
x = r cos(angle) ; z = r sin(angle)
```

Same feature → same position across searches, models, and page reloads. Scaffold dots use the same function with synthetic indices (e.g. `index = 1_000_000 + i`) so they never collide with real hits.

## 8. State (single store, zustand)

```ts
{
  q: string; mode: "fast" | "deep"; view: "gemma-2-2b" | "llama3.1-8b" | "compare";
  manifest: Manifest | null;
  results: Record<ModelId, { found: number; perLayer: Record<number, number>; hits: Hit[]; score: number; ms: number } | undefined>;
  loading: boolean; error?: string;
  live?: Record<ModelId, Hit[]>;   // stretch: Neuronpedia activations
}
```
`search(q)` is debounced 250 ms, fires one `multi_search`, writes `results`. Scene and score panel are pure views of `results`.

## 9. Failure modes and fallbacks

| Risk | Mitigation |
|---|---|
| Typesense Cloud cluster too small for 1.5M docs | Use ≥1 GB RAM config. Fallback: local Docker `typesense/typesense:30.2` (demo is localhost anyway) — 02 §5. |
| Deep import (server-side embedding) slow | Start it at 5:30 in its own terminal; it's independent of Fast. Fallback: `--per-layer 500`. |
| 3D perf on laptop | Scaffold ≤200 dots/layer via one `<Points>`; hits via one `<Instances>`; no bloom until 9 PM. |
| Neuronpedia data missing for some layer | Pull script logs and skips; manifest reflects actual counts; score normalizes on actual counts. |
| Wi-Fi dies at demo | Typesense Cloud needs internet. Mitigation: local Docker mirror with the same data (02 §5), env switch. |
